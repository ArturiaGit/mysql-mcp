## 一、 布局设计哲学与核心目标 (Layout Philosophy)

作为企业级大模型 MySQL 访问安全网关，控制台同时面向两类用户群体：
1. **DBA / SecOps / 超级管理员**：需要极高的数据密度、即时的安全态势感知、严谨的策略层级区分与**零心流中断**的深挖排查能力。
2. **AI / 后端研发工程师**：需要清晰敏捷的开发者自服务流（PAT 签发、Profile 授权查看、客户端连接片段复制）。

### 核心布局四大法则 (The 4 Structural Pillars)
- **零心流中断 (Zero Flow Disruption)**：排查高危 SQL、查看执行计划与处理审批时，**严禁频繁跳出整页**，统一使用右侧滑出抽屉 (`Sheet`) 呈现深度上下文，始终保留主列表视线。
- **安全法则空间化 (Spatialized Security Rules)**：系统底层的硬安全规则在空间视觉上直接体现——例如“黑名单红框绝对置顶于白名单之上”、“双重漏斗限流垂直级联并以等宽 `AND` 连接”，杜绝误解。
- **高承载密度 (Data-Dense 8/10)**：表格行高控制在 **36px~38px**，栅格间距 `12px~16px`，保障 1080P/2K 屏幕下的单屏信息承载力，杜绝消费级 Web 的无意义大留白。
- **自适应视口弹性降级 (Graceful Degradation)**：以专业宽屏桌面为主（1280px~1920px+），同时无缝向便携本、平板和移动端“急症模式”降级。

## 三、 核心区域规格详细定义

### 3.1 左侧导航栏 (Left Sidebar)
- **尺寸标准**：展开宽度 `240px`，收起宽度 `64px`，通过 CSS 变量 `var(--sidebar-width)` 统一驱动，折叠动效 `180ms ease-out`。
- **纵向结构划分**：
  1. **Brand 区域 (高度 64px)**：
     - 网关盾牌 Logo + 名称 `MySQL MCP.` + 副标 `GATEWAY CONSOLE`。
     - 当前环境标识胶囊（`PROD-01` 或 `STAGING`）。
  2. **Navigation 菜单区 (自适应滚动)**：
     - **分组 1 · 运维与监控 (Operations)**：
       - `工作台大盘 (Dashboard)`：KPI 卡片、双重漏斗实时 QPM 曲线。
       - `全链路审计 (Audit Trail)`：同步/异步 SQL 流水，带未读拦截告警微红点。
     - **分组 2 · 安全与管控 (Security & Governance)**（仅管理员展示）：
       - `账号与审批 (Approvals)`：待审批注册申请（内嵌动态计数 Badge，如 `[3]`）。
       - `角色与策略 (RBAC & ACL)`：Profile 授权、表级黑白名单矩阵。
       - `限流与熔断 (Rate Limits)`：双桶配置、Agent 死循环熔断阈值。
       - `数据源配置 (Profiles)`：MySQL 实例、TLS 证书、SSH 堡垒机配置。
     - **分组 3 · 开发者自服务 (Developer Portal)**（全员展示）：
       - `我的凭据 (PAT Tokens)`：个人令牌签发、有效时间感知。
       - `客户端接入 (Client Config)`：Claude Desktop / Codex / Dify 一键配置片段。
       - `个人查询历史 (My Queries)`：个人维度的 SQL 审计流水回溯。
  3. **Sidebar 底部状态区 (固定底部)**：
     - 显示网关内核版本号（`v2.3.0 Production`）。
     - 底层活跃物理连接数指示。
     - SSE 网关长连接健康状态（绿点 `Live`）。

### 3.2 全局顶栏 (Global Top Bar)
- **尺寸标准**：固定高度 `56px`，固定置顶 (`sticky top-0 z-20`)，底边使用 `1px solid var(--border)`。
- **横向布局分布**：
  - **左侧 (Context & Path)**：
    - 侧栏手动折叠/展开图标按钮。
    - 动态层级面包屑（Breadcrumb）：如 `安全与管控 > 数据源配置 > prod_readonly`。
  - **中间偏右 (Global Capabilities)**：
    - **全局指令面板入口 (Command Palette Trigger)**：快捷键提示 `<kbd>Ctrl K</kbd>`，点击展开全站 Command 浮层。
    - **核心防护运行状态徽章**：`Fail-Closed: Active` (绿色微点)、`Dual-Bucket: On` (天蓝微点)。
  - **右侧 (Global Actions & Profile)**：
    - 明暗主题一键切换按钮（Sun/Moon，支持持久化存储）。
    - 展台/系统帮助与快捷键说明入口 (`Help`)。
    - 用户头像与称号下拉菜单（个人信息、强制改密状态、登出）。

### 3.3 右侧排查抽屉 (Right Inspection Sheet)
- **定位与尺寸**：从视口最右侧水平滑入，宽度标准：
  - 宽屏 (`>= 1440px`)：`600px`。
  - 紧凑桌面 (`1024px ~ 1439px`)：`540px`。
  - 移动设备 (`< 768px`)：降级为底部拉起的 `Drawer`（占视口高度 85%）。
- **组件内部布局结构**：
  - **Sheet Header (固定)**：事件唯一 ID（`evt_xxx`）、精确时间戳、放行/拦截语义 Badge、复制当前 ID 按钮。
  - **Sheet Body (独立垂直滚动)**：
    - **SQL 文本卡片**：Monospace 格式化，高亮显示注入的 `LIMIT` 或触发拦截的高危函数。
    - **AST 真实表穿透卡片**：递归穿透后的真实物理表清单、表注释、ACL 判定路径。
    - **执行计划 (EXPLAIN) 卡片**：全表扫描 (`ALL`) 标红预警、索引命中情况、预估行数。
    - **调用链网络卡片**：客户端 IP、McpSession 逻辑会话 ID、所使用的 PAT 摘要前缀。
  - **Sheet Footer (固定底部)**：
    - “复制脱敏 SQL”按钮。
    - 管理员操作区（若命中高危）：提供“一键阻断该 PAT”、“强制断开当前连接 (Kill Query)”。

## 四、 四大业务场景专属页面级布局范式 (Page-Level Layout Patterns)

### 4.1 范式一：工作台安全运维大盘 (Bento Grid 仪表盘)
*适用于：`工作台概览 (Dashboard)`*

采用基于 **12 列响应式网格** 的现代 Bento Grid 布局，将全局安全态势与限流健康度一屏尽览：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [Page Header] 工作台概览                          [自动刷新: 10s ▾]  [时间范围: 今日 ▾] │
├───────────────────┬───────────────────┬───────────────────┬────────────────────────────┤
│ MCP 调用总量      │ 当前活跃会话      │ 高危拦截统计      │ 待审批申请                 │
│ 24,891 (↗ 12.4%)  │ 128 (6 Profiles)  │ 23 (全部阻断)     │ 3 条待审批 (Amber高亮)     │
├───────────────────┴───────────────────┴───────────────────┴────────────────────────────┤
│ [核心流量与限流监控 (占 8 列)]                            │ [高危拦截实时流 (占 4 列)] │
│ 实时聚合 QPM 吞吐 vs Profile 资源承载上限 (双折线对比图)  │ 实时推送的拦截事件瀑布流   │
```

### 4.2 范式二：全链路审计与日志检索 (Dense Table + Sheet 抽屉)
*适用于：`全链路 SQL 审计大盘`、`用户管理列表`、`审批工单中心`*

- **布局结构**：
  1. **顶部紧凑筛选栏 (Filter Toolbar)**：
     - 左侧：快捷状态切换 Tab（`全部 (6)`、`已放行 (3)`、`已拦截 (2)`、`慢查询 (1)`）。
     - 右侧：组合过滤区：`[SQL / 用户名搜索框]` + `[Profile 下拉]` + `[时间范围]` + `[导出 CSV 按钮]`。
  2. **高密度数据表格区 (Table Container)**：
     - 外层容器必须设置 `overflow-x: auto; max-width: 100%`。
     - 表头固定 (`sticky top-0 z-10`)，行高控制在 **36px~38px**。
     - SQL 列限制最大宽度（`max-w-[320px]`），单行超出截断 (`truncate`)。
     - 行末提供显式下钻按钮或整行点击，**点击直接触发右侧 `Sheet` 抽屉展开**。
  3. **底部紧凑汇总栏 (Footer)**：
     - 当前筛选展示记录数（如 `显示 6 / 24,891 条记录`）。
     - 分页控制器（页码、每页条数）。

### 4.3 范式三：策略与限流配置矩阵 (分栏/分区编辑布局)
*适用于：`角色权限与表级 ACL`、`双重漏斗限流与熔断中心`*

- **空间表达安全优先法则**：
  - **表级 ACL 策略中心**：
    - **顶部红框危险区 (Blacklist)**：黑名单规则卡片绝对置顶，边框使用 `border-destructive/30 bg-destructive/5`，标注：“🚨 黑名单具有最高优先级，命中即阻断”。
    - **中部蓝框授权区 (Whitelist)**：白名单授权库表，标签展示通配符（如 `order_*`）。
    - **右侧/底部实时演练沙盒 (AST Simulator)**：提供“SQL 规则实时验证器”，输入测试 SQL，即时显示递归穿透后的物理表及是否会触发拒绝。
  - **双重漏斗限流中心**：
    - 垂直堆叠两张配置卡片，中间插入等宽逻辑标记 `[ ∧ AND ]`：
      - 上层：**主体配额桶 (User Bucket)** 配置（配额滑动条 + `-1` 免限流勾选）。
      - 中间：**等宽 AND 衔接栏**。
      - 下层：**资源保护桶 (Profile Capacity Bucket)** 配置（Profile 全局并发上限）。
    - 醒目视觉标注：“任何免限流配置绝不可穿透底层资源保护桶”。

### 4.4 范式四：开发者自服务门户 (向导与代码卡片布局)
*适用于：`个人凭据中心 (PAT)`、`客户端接入向导`*

- **单列聚焦卡片流 (Single-Column Focus)**：
  - **卡片 1 · 账号状态与权限域**：
    - 状态徽章（`ACTIVE` 已激活 / `PENDING` 待审批）。
    - 当前账号被允许访问的 Profile 列表（标签形式展开）。
  - **卡片 2 · 个人访问令牌 (PAT) 签发**：
    - 点击“生成新 PAT”弹出**单次展示保护弹窗 (`Dialog`)**。
    - 弹窗顶部附带不可逆风险警示横幅。
    - 包含等宽令牌字符串、一键复制按钮、“我已妥善保存”强校验勾选框（勾选后方允许关闭）。
  - **卡片 3 · 客户端配置片段生成器**：
    - 顶部 Tab 选项卡：`[Claude Desktop (JSON)]` | `[Codex 配置]` | `[通用 curl / SSE]`。
    - 主体为 Monospace 代码块，内置语法高亮，右上方常驻“一键复制完整配置”按钮。

## 七、 键盘导航与无障碍焦点管理准则 (Accessibility & Focus Flow)

1. **跳过链接 (Skip Link)**：页面首个可聚焦元素必须是“跳转到主内容区” (`.skip-link`)，便于纯键盘使用者跳过侧边栏直达主画布。
2. **抽屉与弹窗焦点陷阱 (Focus Trapping)**：
   - 当右侧 `Sheet` 或模态 `Dialog` 打开时，焦点必须自动锁定在内部（首个聚焦项或关闭按钮），页面底层主内容必须声明 `aria-hidden="true"` 或 `inert`。
   - 按 `Esc` 键必须平滑关闭当前最顶层浮层并**将焦点精准归还到触发此操作的原始按钮**。
3. **全局快捷键规范**：
   - `Ctrl+K` / `⌘K`：唤起全局指令搜索面板。
   - `Esc`：关闭抽屉、弹窗或清除搜索框。
   - `Tab` / `Shift+Tab`：严格按照自然视觉阅读顺序进行焦点转移，严禁出现乱序跳转。
